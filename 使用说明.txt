DSH Skill 管理器 · 便携版 v1.0.1
========================================

双击 SkillManager.exe 就能用。不解压也行（zip 里直接双击 exe 也可以，
但那样 skill 会存在临时目录里，建议先解压到一个固定位置）。


这个程序干什么
----------------------------------------
把 DSH 的 skill 列出来，切换「已启用 / 已禁用 / 已归档」三种状态。
改完立刻生效，不用重开 DSH——skill 目录是实时监听的。


三种状态
----------------------------------------
  已启用    两个开关都不写（默认）。模型能自动调用，你也能用 /名字 手动调。
  已禁用    disable-model-invocation: true。模型看不见它、不会被自动调用，
            但你在输入框敲 /名字 仍然能叫出来。
  已归档    文件被挪进 skills\.disabled\。连手动入口都没有，但文件还在，随时能装回来。

装了一堆 skill 又嫌吵的时候，日常该用的是「已禁用」。


skill 放哪
----------------------------------------
就放在本目录的 skills\ 文件夹里：

  SkillManager.exe
  skills\
    我的skill.md            <- 单文件形态
    另一个skill\
      SKILL.md              <- 目录式形态，同目录可以放参考文件和脚本
    .disabled\              <- 归档池，程序自动管理，别手动往里放

必须是 skills\ 的第一层，往子目录里塞不会被发现。


一个 skill 长什么样
----------------------------------------
  ---
  name: 我的skill
  description: 一句话说清什么时候该用它——DSH 主要靠这句判断要不要调用
  ---

  在这里写完整说明。

name 和 description 都要有，缺任何一个这个 skill 都不会被 DSH 加载
（程序里会标红提醒）。


和 DSH 的关系（重要）
----------------------------------------
这个程序管理的是「本目录下的 skills\」，DSH 默认不会去扫它。
想让 DSH 用上这里管理的 skill，有两种办法：

  1. 把 skills\ 里的文件复制到 DSH 会扫的目录，通常长这样：
       <你打开 DSH 的那个工作目录>\.dsh\skills\     （跟着工作目录走）
       C:\Users\<你的用户名>\.dsh\skills\           （全局，所有项目共用）

  2. 或者用下面这个更省事的办法：直接在界面上把根目录切过去。

     根目录那一行可以直接输入或粘贴路径，回车就切过去。
     你切过的目录会记在 exe 旁边的 roots.txt 里，下次打开自动用它，不用每次重选。
     右边的「最近」下拉就是 roots.txt 里的历史记录。

     想固定一个默认目录，就在本目录建一个 portable.txt，里面写一行路径。
     优先级：roots.txt（你上次选的） > portable.txt（你固定的） > skills\ > exe 所在目录。

     如果你手上没有 skill，就先拿 skills\ 目录练手，或者点「新建 skill」自己造一个（名字和说明都必填，创建后会直接用记事本打开）。


关于那些自动生成的文件（删了也没事）
----------------------------------------
  roots.txt      记你上次选的目录。删掉之后程序会回到 skills\ 目录。
  crash.txt      只有程序崩溃时才出现，里面是出错信息，排查用。
  version.txt    跑 --version 时生成，里面是编译时间和当前根目录。
  *.bak          备份文件，确认新版没问题就可以删。

  上面这些都不是程序运行必需的，删掉不影响使用。


命令行参数（排查用）
----------------------------------------
  SkillManager.exe --version                     看版本、编译时间、当前根目录
  SkillManager.exe --selftest --out 报告.txt     跑内核自检（36 项断言）
  SkillManager.exe --smoke --out 报告.txt        只搭界面、扫一遍目录就退出
  SkillManager.exe --smoke --smoke-state --out 报告.txt   额外验证状态切换
  SkillManager.exe --smoke --smoke-state --smoke-undo --out 报告.txt  再加上撤销
  SkillManager.exe --check-ui --out 报告.txt     会真的渲染一次窗口，验证两个自绘模板
                                                 （下拉框能不能点开、禁用按钮是不是深色底）
  SkillManager.exe --screenshot --out 图.png    把主界面渲染成 PNG（更新 README 截图用）

这些参数都不弹窗口、不弹任何对话框，结果写进你指定的文件。
程序崩溃时会在同目录留下 crash.txt（只有异常类型和消息，没有调用栈）。

分不清"是不是还在用旧版"的时候，先跑一次 --version，看编译时间对不对。


自己重新编译
----------------------------------------
双击 src\build.cmd 即可（用的是 Windows 自带的 C# 编译器，不用装任何东西）。
编译产物是单个 exe，不依赖 .NET 之外的运行时。


界面说明
----------------------------------------
  最左边的圆点 = 状态指示灯：绿=已启用，灰=已禁用，橙=已归档。它不能点。
  改状态请用「状态」那一列的下拉。状态文字用亮色加粗，方便一眼扫出来。
  「撤销刚才的改动」只记最近一次，批量改动不支持撤销。

  顶部「skill 根目录」那一行：
    路径框     —— 可以直接编辑，输入或粘贴路径后按回车切换；按 Esc 放弃修改。
                  切到不存在的目录会问你要不要创建。
    浏览…      —— 打开系统的文件夹选择框。
    便携目录   —— 一键回到 exe 旁边的 skills\。
    最近       —— 下拉列出 roots.txt 里记过的目录，点一下就切过去。

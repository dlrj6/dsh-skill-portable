DSH Skill 管理器 · 便携版 v1.0.0
========================================

双击 SkillManager.exe 就能用。不用安装、不联网、不写注册表。
建议先解压到一个固定目录（别在压缩包里直接双击，那样 skill 会存在临时目录里）。
详细版说明见 README.md；这份 txt 只讲最常用的部分。

系统要求：Windows 10 / 11（自带 .NET Framework 4.x 即可）。
exe 没签名，首次运行 SmartScreen 可能拦一下：更多信息 → 仍要运行。


这个程序干什么
----------------------------------------
把 skill 列出来，切换「已启用 / 已禁用 / 已卸载」三种状态。
改完立刻生效，不用重开 DSH（skill 目录是实时监听的）。
它只管你界面上显示的那个目录，不会自己去找 DSH。


三种状态
----------------------------------------
  已启用    两个开关都不写（默认）。模型能自动调用，你也能 /名字 手动调。
  已禁用    disable-model-invocation: true。模型看不见、不会自动调用，
            但你在输入框敲 /名字 仍然能叫出来。
  已卸载    文件被挪进 skills\.disabled\，同时写 user-invocable: false。
            连手动入口都没有，但文件还在，随时能切回来。

装了一堆 skill 又嫌吵的时候，日常该用的是「已禁用」。
「彻底删除」才真的删文件，删之前会二次确认。


skill 放哪
----------------------------------------
就放在根目录（默认是 exe 旁边的 skills\）的第一层：

  SkillManager.exe
  skills\
    我的skill.md            <- 单文件形态
    另一个skill\
      SKILL.md              <- 目录式形态，同目录可以放参考文件和脚本
    .disabled\              <- 停用池，程序自己管理，别手动往里放

往子目录里塞不会被发现。


一个 skill 长什么样
----------------------------------------
  ---
  name: 我的skill
  description: 一句话说清什么时候该用它——DSH 主要靠这句判断要不要调用
  ---

  在这里写完整说明。

name 和 description 都要有，缺任何一个这个 skill 都不会被加载
（程序里会标红提醒）。


接到你自己的 DSH
----------------------------------------
把顶部「skill 根目录」路径框指到 DSH 真正扫描的目录，回车：

  C:\Users\<你的用户名>\.dsh\skills\        （全局）
  <你打开 DSH 的工作目录>\.dsh\skills\      （跟着项目走）

切过去之后会自动记住（记在 exe 旁边的 roots.txt）。
右边的「最近」下拉就是 history，点一下就切回去。

根目录优先级：
  roots.txt（上次选的） > portable.txt（你固定的） > skills\ > exe 所在目录
想固定一个默认目录，就在 exe 旁边建 portable.txt，里面写一行路径。


界面速览
----------------------------------------
  最左边的圆点 = 状态灯（绿=启用，灰=禁用，橙=卸载），它不能点。
  改状态用「状态」列的下拉。
  「撤销刚才的改动」只记最近一次，批量改动不支持撤销。
  「查看停用池」打开 .disabled\ 目录。
  「新建 skill」可以造一个带 frontmatter 的空 skill。


命令行参数（排查用，结果写文件、不弹窗）
----------------------------------------
  SkillManager.exe --version                     看版本、编译时间、当前根目录
  SkillManager.exe --selftest --out 报告.txt     内核自检（32 项断言）
  SkillManager.exe --smoke --out 报告.txt        只搭界面、扫目录就退出
  SkillManager.exe --check-ui --out 报告.txt     真渲染一次，验证下拉框/按钮模板

分不清是不是旧版，先跑 --version 看编译时间。
崩溃时同目录会留 crash.txt（只有异常类型和消息）。


常见问题
----------------------------------------
Q: 改了状态，DSH 里没变化？
A: 根目录指错了。把路径框指到 DSH 真正扫描的 skills 目录再改。

Q: 程序会联网 / 收集信息吗？
A: 不会。没有网络调用，不写注册表，不读机器码或用户名。
   只在 exe 旁边生成几个自己的文本文件（roots.txt / crash.txt / version.txt）。

Q: 这些自动生成的文件能删吗？
A: 能。都不是运行必需的。给别人之前建议删掉 roots.txt（里面有你的本机路径）。

Q: 能放 U 盘吗？
A: 能，整个文件夹拷走就行。


自己重新编译（可选）
----------------------------------------
双击 src\build.cmd（用 Windows 自带的 C# 编译器，不用装任何东西）。
产物是根目录的 SkillManager.exe。源码和更多说明见 README.md / docs\DEVELOPMENT.md。
